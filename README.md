# 🎙️ VoiceInterview AI

An AI-powered **voice interview coach**. You log in, pick your level and technology, and an AI interviewer **asks questions out loud**. You **answer by speaking**, the AI **listens, tells you whether you were right, reads out the correct answer**, and at the end gives you an **overall score with coaching feedback**.

## Features

- Register and login with JWT authentication (bcrypt password hashing)
- Choose level (Beginner, Intermediate, Advanced), technology (JavaScript, TypeScript, React, Angular, Node.js, Express.js, MongoDB, HTML and CSS, Next.js, Vue.js, Python, Java), number of questions and voice accent
- Questions generated by Google Gemini for the chosen level and technology
- Text to speech (the AI reads questions, feedback and the correct answer) and speech to text (your spoken answer) using the browser Web Speech API
- You can edit the transcript or type instead of speaking, and skip a question
- Every answer gets a score from 0 to 10, a verdict (correct, partially correct, incorrect), feedback and the ideal answer
- Final score out of 100, strengths, areas to improve, and a question by question review
- Interview history, and resume an unfinished interview

## Setup

### 1. Requirements

- Node.js 20.19 or newer (`node -v`)
- A MongoDB database: local, or a free MongoDB Atlas cluster
- A Gemini API key from https://aistudio.google.com/apikey

### 2. Install

```bash
npm run install:all
```

### 3. Configure environment variables

```bash
# macOS / Linux
cp server/.env.example server/.env
# Windows PowerShell
Copy-Item server/.env.example server/.env
```

Edit `server/.env`:

| Variable | Description |
| --- | --- |
| `MONGODB_URI` | MongoDB connection string |
| `JWT_SECRET` | Random string, at least 32 characters |
| `GEMINI_API_KEY` | Your Gemini API key |
| `GEMINI_MODEL` | Optional, defaults to `gemini-2.5-flash` |
| `CLIENT_ORIGIN` | Frontend origin(s), comma separated. Default `http://localhost:5173` |

Generate a secret quickly with:

```bash
node -e "console.log(require('crypto').randomBytes(48).toString('hex'))"
```

### 4. Run

```bash
npm run dev
```

- Frontend: http://localhost:5173
- API: http://localhost:5000 (health check at `/api/health`)

Open the app in **Google Chrome or Microsoft Edge** and allow microphone access when asked.

## How it works

```
Browser (React)                                Express API                    Gemini      MongoDB
───────────────                                ───────────                    ──────      ───────
Select level + tech ── POST /api/interviews ─▶ generate N questions ───────▶ JSON  ───▶ save interview
AI reads question (speechSynthesis)
User speaks (SpeechRecognition) → transcript
Submit ─────────────── POST /:id/answer ─────▶ evaluate answer ────────────▶ score,
                                               update interview atomically     feedback,
AI reads verdict + correct answer ◀──────────  verdict + next question         correct answer
...last answer ─────── final score + coach summary ───────────────────────▶ summary ──▶ completed
```

### API

| Method | Endpoint | Description |
| --- | --- | --- |
| POST | `/api/auth/register` | Create account |
| POST | `/api/auth/login` | Log in |
| GET | `/api/auth/me` | Current user |
| GET | `/api/interviews/options` | Levels, technologies, question counts |
| POST | `/api/interviews` | Start interview (generates questions) |
| GET | `/api/interviews` | Interview history |
| GET | `/api/interviews/:id` | Interview state, or full results when completed |
| POST | `/api/interviews/:id/answer` | Submit answer, get evaluation and next question |

Interview endpoints require `Authorization: Bearer <token>`.

## Design notes

- **Questions are generated once per interview** and stored, so each answer needs only one AI call and the interview can be resumed.
- **The correct answer is never sent to the browser before the user answers.**
- **Answers are treated as untrusted input.** The evaluation prompt tells the model to ignore instructions inside the answer, and AI output is validated with Zod. The score is clamped to 0 to 10 and the verdict is derived from it in code.
- **Atomic update on submit**: the save is filtered on the current question index, so a double click cannot score the same question twice.
- **The final summary can fail without losing the interview**: the score is computed in code and a fallback message is used if the AI call fails.

## Browser support and limits

- Speech recognition works in Chrome and Edge. Safari support is partial and Firefox does not support it, but typing always works.
- Chrome sends audio to Google for transcription, so it needs an internet connection.
- Microphone access needs HTTPS in production (`localhost` is fine).
- Gemini free tier has rate limits. If you see "AI service unavailable", wait a minute and retry.

## Deployment (GitHub + Vercel)

One GitHub repo (monorepo) with two Vercel projects, both pointing at the same repo:

| Vercel project | Root Directory | Framework | Environment variables |
| --- | --- | --- | --- |
| API | `server` | Other | `MONGODB_URI`, `JWT_SECRET`, `GEMINI_API_KEY`, `GEMINI_MODEL`, `CLIENT_ORIGIN`, `NODE_ENV=production` |
| Web | `client` | Vite | `VITE_API_URL` (the API project URL, no trailing slash) |

Order: deploy the API first, then the web app with `VITE_API_URL`, then set `CLIENT_ORIGIN` on the API to the web URL (no trailing slash) and redeploy the API.

- `server/api/index.js` is the serverless entry point and `server/vercel.json` routes every request to it.
- `client/vercel.json` rewrites all routes to `index.html` so React Router works on refresh.
- In MongoDB Atlas, allow `0.0.0.0/0` under Network Access (Vercel IPs are not fixed).
- Never commit `.env`. Add secrets only in Vercel project settings.
